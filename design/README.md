# 子木 · 股票智能助理 — 界面原型

纯前端 HTML / CSS / JS 原型：无构建、无外部依赖、断网也能跑。用来验证一个**个人股票助理**的信息架构与交互 —— 持仓管理、行情追踪、AI 分析与买卖建议、组合诊断、微信推送接入。

> 当前是**设计原型**：行情、持仓、净值、分析结论全部来自 `assets/data.js` 里的演示样本，未接入任何行情源或模型，不构成投资建议。

## 打开方式

直接双击 `index.html` 即可。想用本地服务：

```bash
python -m http.server 8000 --directory design
# 浏览器打开 http://localhost:8000/
```

| 文件 | 界面 | 关键交互 |
|---|---|---|

| `dashboard.html` | 总览仪表盘 | 净值 vs 沪深300（十字准星 tooltip）、可切近一周/一月/一季、当日盈亏归因、待处理预警可逐条归档、持仓 sparkline、收盘摘要 |

## 设计约定

- 视觉方向：现代极简（浅色）。色彩/字体/间距令牌集中在 `assets/ui.css` 的 `:root`，全部用 `oklch()`。
- **涨跌配色按 A 股惯例**：红涨 `--up`、绿跌 `--down`，只作用于数字与标记，不做装饰。
- `--accent` 只用于交互态（主按钮、选中项、焦点环），每屏不超过两处。
- 所有数字等宽对齐：`font-variant-numeric: tabular-nums`，代码/价格走 `--font-mono`。
- 卡片无投影、只用 1px 发丝边框；圆角 6 / 10 / 14px 三档。
- 断点：`1360`（双列转单列）→ `1180`（侧栏收成图标栏）→ `900`（侧栏转抽屉 + 底部标签栏）→ `520` → `380`。

## 数据契约

换真实数据时**只需改 `assets/data.js`**，页面逻辑不用动。它挂在全局 `window.ZM` 上：

| 字段 | 说明 |
|---|---|
| `holdings[]` | 每只标的：`code / name / mkt / kind(stock\|etf\|cb) / sector / shares / cost / price / prev`。`dayChg / dayVal / mv / pnl / pnlPct / weight` 由代码派生，**不要手填** |
| `indices[]` | 顶部行情条的指数快照 |
| `equity{}` | `dates / nav / bench`，净值与基准已归一到同一起点 |
| `advice{}` | 按 `code` 存分析结论：`score / action / horizon / conf / position / target / stop / reason / dims[4] / risks[]` |
| `alerts[] / watchlist[] / qa[] / sessions[]` | 预警、自选、问答样本、微信会话 |
| `marketClock()` | 真实交易时段逻辑：9:15 集合竞价、9:30–11:30、13:00–15:00、盘后定价、周末休市并给出下一时段倒计时 |

总资产、当日与累计盈亏、仓位占比、行业权重、HHI、年化波动、最大回撤、相关系数等汇总指标**全部由持仓与 `equity` 计算得出**，页面里不写死数字 —— 新增指标时请沿用同一口径，避免文案与图表打架。

## 已内置的业务规则

- **整手**：股票 / 场内 ETF 100 股一手，可转债 10 张一手；数量按手校验。
- **报价小数位**：按 `kind` 统一（股票 2 位、ETF / 转债 3 位），唯一出处是 `data.js` 的 `priceDec(kind)`，页面不得手搓精度（转债一律 `126.720` 三位）。
- **费用估算**：佣金万 2.5（单笔最低 5 元）+ 卖出印花税 0.05% + 过户费 0.001%（2022-04-29 起沪深两市均收）；ETF 与可转债免印花税。实际以券商结算为准。
- **摊薄成本**：买入按 `(成本 × 持仓 + 成交额 + 费用) / 新持仓` 重算；卖出扣减持仓并计算已实现盈亏。
- **价格校验**：偏离昨收超过涨跌停区间的委托价判为非法（主板 ±10%，转债按 ±20% 口径放宽）。
- **仓位纪律**：单票 ≤25%、单行业 ≤35%、现金 ≥10%、可转债合计 ≤12%；触及即在「组合诊断」生成再平衡条目。
- **波动测算假设**：组合年化波动由各标的 30 日收益标准差按权重合成，跨行业相关系数取 0.35、同行业取 0.62。这是标注在页面上的**假设值**，不代表未来表现。

## 浏览器本地状态

| 键 | 内容 |
|---|---|
| `zimu:chat:me` | 问答会话，最多保留最近 30 条 |
| `zimu:wechat:v2` | 微信接入的通道开关、订阅、静音标的、绑定状态 |

清掉站点数据即恢复默认。演示时若不想带上你点过的状态，用无痕窗口打开。

## 已知边界

- 单用户、单账户，没有登录与权限模型。
- 覆盖沪深市场：A 股、场内 ETF、可转债；未做港股、美股、场外基金。
- 无后端：不读取券商账户、不代提交委托，加减仓只是本地试算。
- 分析结论的「置信度」指样本内信号一致性，不是胜率预测。
