## 写作规范

- **一个事实只写一处。** 口径进 03，字段进 04，界面职责进 02；其他文档只引用不复述。
- 与代码有关的描述都要带 `文件:行号`，代码变了才发现文档过期，比没有文档更糟——所以宁可留锚点。
- 有取舍的改动先补 ADR 再改代码；只记「为什么不做什么」和「为什么这样做」，不记流水账。
- 文档与 `design/README.md` 冲突时以 `docs/` 为准（原型说明将逐步收敛为链接）。
- 简体中文正文，技术标识符、字段名、文件名保持英文原样。
