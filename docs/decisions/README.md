# 决策记录（ADR）

这里有且只放「为什么不那样做」。代码会自己解释怎么做，文档要解释为什么选这条路——半年后没人记得。

## 什么时候补一条

- 在两个可行方案里选了一个
- 明确决定**不做**某件事
- 推翻了之前的决定
- 引入了新的依赖、框架、服务、数据源

改一个界面不需要 ADR；给项目加一套构建工具需要。

## 格式

文件名 `NNNN-<kebab-slug>.md`，编号递增，不复用、不删除（被取代的改为 `已取代 by NNNN`）。

```markdown
# NNNN · 标题

- **状态**：提议 / 接受 / 已取代（by NNNN）
- **日期**：YYYY-MM-DD
- **决策者**：

## 背景
什么压力让我们必须选一个。

## 决定
选了什么，一句话说清。

## 选项与取舍
A …（选/不选，为什么）
B …

## 后果
正面、负面、以及「以后要改回来得动哪里」。
```
